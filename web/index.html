How This System Protects Your Laptop

        
A standard computer relies on simple antivirus that only reacts after malware runs. This project provides a complete 4-Layer Defense Architecture that monitors, detects, correlates, and automatically contains threats in real time.

      


      

        
        

          
01

          
SENSORY LAYER (THE EYES)

          
Microsoft Sysmon

          
Runs at the Windows kernel level. Unlike basic logging, it calculates cryptographic SHA256 hashes of every program, inspects full command lines, and tracks all inbound/outbound network connections.

        


        

          
02

          
TRANSPORT LAYER (NERVES)

          
Wazuh Endpoint Agent

          
Securely ingests Windows EventChannels, Sysmon logs, and file changes in real time. It encrypts this telemetry and streams it to the central SIEM manager over TLS port 1514.

        


        

          
03

          
ANALYSIS LAYER (THE BRAIN)

          
SIEM Correlation Engine

          
Matches incoming logs against custom detection rules and IOC blacklists. It can correlate multiple events over time (e.g. 3 failed logins in 60 seconds) to detect sophisticated attacks.

        


        

          
04

          
DEFENSE LAYER (THE SHIELD)

          
Automated Incident Containment

          
Takes active defensive action: immediately isolates the computer from malicious C2 IPs via firewall rules, moves threat artifacts into a secure quarantine vault, and restores clean state.
